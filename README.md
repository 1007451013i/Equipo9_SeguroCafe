# Equipo 9 — Seguro Agrícola Indexado para Café

Proyecto aplicado — Maestría en Inteligencia Analítica de Datos (MIAD), Universidad de los Andes.

## Versión oficial de entrega — Fase 3

La versión oficial del prototipo correspondiente a la entrega final se encuentra en:

`Entrega_Fase3_Ajustada/solucion_local_sai_f3_ENTREGA/`

Esta es la versión que debe utilizarse para la instalación, ejecución y evaluación del artefacto.

Las demás carpetas del repositorio se conservan como histórico del proceso de desarrollo y no corresponden a la versión final objeto de evaluación.

Dentro de la carpeta oficial se encuentran el código del dashboard y la API, el paquete de modelos, los archivos de soporte y las instrucciones necesarias para ejecutar la solución.
